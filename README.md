# Nerve — Repo de Evaluación

Este repositorio fue generado automáticamente para ti. Aquí resolverás los retos
de cada módulo de Python.

## Cómo funciona

1. Ve a la carpeta del nivel que corresponds (ej. `python/Modulo-01-Fundamentos/01-hola-mundo/`)
2. Lee el archivo `reto.md`
3. Crea el archivo `reto.py` y resuelve el reto
4. Haz commit y push
5. GitHub Actions evaluará tu solución automáticamente

## Reglas

- Solo debes editar `reto.py` (o el archivo que indique el reto)
- **No modifiques `test_main.py`** — el servidor lo reemplaza con la versión oficial
  antes de cada evaluación, así que cualquier cambio será ignorado
- Un reto está aprobado cuando todos sus tests aparecen en verde ✓
